02 / QUICK START

第一次使用，
從這裡開始。

先安裝 uv，再開啟終端機。以下指令安裝 GitHub 的 v0.3.0 版本；需要 Git。

PyPI 套件預計命名為 anicat，目前尚未發布，請使用這裡的 GitHub 安裝方式。新站 HLS 功能目前在開發版本中。

1. 安裝工具
uv tool install "git+https://github.com/HeiTang/AniCat-v2.git@v0.3.0"
2. 下載第一集
anicat https://anime1.me/15651
指定資料夾、批次與併發 
anicat URL1 URL2 -o ./Videos -c 2
anicat --help

把 URL1、URL2 換成實際網址。預設資料夾是目前位置下的 Anime1_Download。

04 / GOOD TO KNOW

卡住了？
先看這幾件事。

安裝後找不到 anicat 指令？

執行 uv tool update-shell，關閉並重新開啟終端機，再試 anicat --help。

下載失敗後能接續嗎？

Direct MP4 預設使用同資料夾內的 .mp4.part 暫存檔續傳。不要刪掉暫存檔，重新執行原指令即可。開發中的 HLS 目前失敗後會從頭下載。

這個網頁可以直接下載影片嗎？

這裡提供介紹與操作說明，下載由安裝在你電腦上的 AniCat 執行。已發布的 v0.3.0 尚無圖形介面；獨立 GUI 開發分支提供桌面視窗，需要 Python Tk 支援，尚未包含在此網站分支或已發布版本。

如何回報問題？

附上版本、來源網址、執行指令與錯誤訊息，到 GitHub Issues 回報。請先移除 cookies 或其他私人資訊。
