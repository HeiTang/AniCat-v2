01 / THE FLOW

少一點重複操作。
多一點自己的時間。

01

找到想看的

先在支援站點找到作品，再貼上單集、分類或季度網址；不用記住額外的搜尋指令。

02

一次處理多集

一次貼上多個網址，或交給工具展開整季。需要時再用 -c 調整同時下載的集數。

03

留在你的資料夾

對能直接提供 MP4 影片的來源，下載中會先保留 .mp4.part 暫存檔；中斷後重新執行相同指令，就能從暫存位置接著下載。

02 / QUICK START

第一次使用，
從這裡開始。

先安裝 uv（用來安裝 Python 工具的管理程式），再開啟終端機。以下指令安裝 GitHub 的 v0.3.0 版本；電腦也需要 Git。

PyPI 套件預計命名為 anicat，目前尚未發布，請使用這裡的 GitHub 安裝方式。桌面介面與新站支援仍在開發中、尚未發布。 開發版桌面介面安裝時會一起準備影片處理工具，檢查失敗時也會提供修復說明。

1. 安裝工具
uv tool install "git+https://github.com/HeiTang/AniCat-v2.git@v0.3.0"
2. 下載第一集
anicat https://anime1.me/15651
指定資料夾、批次與併發 
anicat URL1 URL2 -o ./Videos -c 2
anicat --help

把 URL1、URL2 換成實際網址。-o 指定輸出資料夾， -c 2 代表同時下載 2 集；不指定時會使用目前位置下的 Anime1_Download。這些是進階設定，不改也能先下載。

04 / GOOD TO KNOW

卡住了？
先看這幾件事。

安裝後找不到 anicat 指令？

執行 uv tool update-shell，關閉並重新開啟終端機，再試 anicat --help。

下載失敗後能接續嗎？

可以。能直接取得 MP4 的來源會在同資料夾留下 .mp4.part 暫存檔；它不是最後完成的影片，請不要刪除。重新執行原指令即可從暫存位置繼續。 開發中的串流影片目前失敗後會從頭下載，尚未發布。

這個網頁可以直接下載影片嗎？

這裡提供介紹與操作說明，下載由安裝在你電腦上的 AniCat 執行。已發布的 v0.3.0 尚無圖形介面；獨立 GUI 開發分支提供桌面視窗，需要 Python Tk 支援，尚未包含在此網站分支或已發布版本。

如何回報問題？

附上版本、來源網址、執行指令與錯誤訊息，到 GitHub Issues 回報。請先移除 cookies 或其他私人資訊。
