把 Anime1 網址貼進 App，一次下載單集或整季。選好資料夾，就能在佇列裡查看每集進度。

安裝桌面 App 命令列版 v0.3.0

桌面 App 為開發預覽，需從原始碼安裝。

安裝桌面 App

先準備 Git、支援 Tk 的 Python 3.12 以上版本，以及 uv。 在終端機執行下列指令，開啟開發預覽版。

目前尚無桌面安裝包。HLS 所需的 FFmpeg 通常會隨依賴一起安裝。

從 GitHub 原始碼安裝並啟動
git clone --branch dev https://github.com/HeiTang/AniCat-v2.git
cd AniCat-v2
uv sync --locked
uv run anicat-gui

用 App 下載影片

貼上作品網址

支援單集、分類與季度網址。多個網址可分行貼上。

查看下載佇列

整季會展開為逐集任務，可查看下載、驗證和完成狀態。

選擇儲存資料夾

影片以 MP4 儲存在本機，App 預設存到 ~/Downloads/AniCat。

命令列版 v0.3.0

這是 AniCat 已發布的版本。在終端機輸入 anicat 和影片網址即可下載。安裝需要 Git 與 uv。

GitHub 發行頁

uv tool install "git+https://github.com/HeiTang/AniCat-v2.git@v0.3.0"

anicat https://anime1.me/15651

卡住了？
先看這幾件事。

安裝後找不到 anicat 指令？

用 uv 從原始碼安裝桌面版時，請在專案目錄執行 uv run anicat-gui。 若用 uv tool 安裝命令列版，可執行 uv tool update-shell， 重開終端機後再試 anicat --help。

下載失敗後能接續嗎？

可以。能直接取得 MP4 的來源會在同資料夾留下 .mp4.part 暫存檔；它不是最後完成的影片，請不要刪除。重新執行原指令即可從暫存位置繼續。 開發中的串流影片目前失敗後會從頭下載，尚未發布。

這個網頁可以直接下載影片嗎？

這裡提供介紹與操作說明，下載由安裝在你電腦上的 AniCat 執行。桌面 App可從 dev 分支安裝，需要 Python Tk。 已發布的 v0.3.0 提供命令列操作。

如何回報問題？

附上版本、來源網址、執行指令與錯誤訊息，到 GitHub Issues 回報。請先移除 cookies 或其他私人資訊。
